## Selected projects

A social-deduction game in development where players interact with both human and AI-controlled witnesses.

### DotaFactory — Content automation

A **local-first content production pipeline** for Dota 2 videos, built with **Python, FFmpeg, APIs, and persistent workflows**.

It supports clip discovery, selection, rendering, metadata generation, guarded publishing workflows, and performance measurement. The system emphasizes **automated tests, quality gates, recovery paths, and human editorial review** rather than unattended publishing.

A repeatable process for creating and delivering websites for small businesses, from requirements and implementation to visual QA and deployment.

Working with **Astro, Cloudflare Pages, Git/GitHub, and AI-assisted development workflows**.

### Tryhard Nutrition — Offline-first Android app

A personal nutrition-tracking application built with **Kotlin, Jetpack Compose, and Room/SQLite**.

Includes food and meal tracking, with ongoing work on **barcode scanning, nutrition-label OCR, and on-device computer vision**. The focus is on local data, offline functionality, and practical mobile UX.
